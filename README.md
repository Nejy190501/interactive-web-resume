A modern, responsive, and minimalist HTML/CSS resume project. This repository contains my personal academic and professional resume, designed from scratch without any heavy frameworks.

---

## 🌟 Features

- **Modern UI**: Clean, card-based design with subtle glassmorphism and shadows.
- **Responsive Design**: Looks great on desktop, tablet, and mobile devices.
- **Multi-page Structure**:
  - `index.html` — Main resume (Education, Work Experience, Skills).
  - `hobbies.html` — Personal hobbies and interests.
  - `contact.html` — Contact information and links.
- **Semantic HTML5**: Fully compliant, accessible markup.
- **No Dependencies**: Pure HTML and CSS (Google Fonts used for typography).

---

## 🚀 How to Run Locally

You don't need any special server to view this project!

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Nejy190501/HTML-Resume.git
   ```
2. **Open it in your browser:**
   Double-click on `index.html` to open it in Chrome, Firefox, Safari, or Edge.
